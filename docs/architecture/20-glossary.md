# 20. Atamalar Izohli Lug'ati (Glossary)

## 1. Atamalar va Qisqartmalar Ro'yxati

| Atama / Qisqartma | To'liq Nomi | Izoh va Ta'rifi |
|---|---|---|
| **PWA** | Progressive Web Application | Veb-saytni mobil ilova shaklida telefonga o'rnatish va offline ishlash imkonini beruvchi texnologiya. |
| **Lazy Auth** | Kechiktirilgan Avtorizatsiya | Sotuvchining avval ma'lumot kiritib, submit bosgandagina avtorizatsiyadan o'tish UX ssenariysi. |
| **Audit Trail** | O'zgarishlar Tarixi | Bazadagi har bir tahrir va o'chirish harakatini "Kim, Qachon, Eski -> Yangi" shaklida o'zgarmas saqlash. |
| **Soft Delete** | Mantiqiy O'chirish | Yozuvni bazadan o'chirmasdan `is_archived = true` belgisi orqali yashirib qo'yish amaliyoti. |
| **Idempotency** | Idempotentlik | Bir xil so'rov (masalan sync request) bir necha bor yuborilganda ham natija faqat 1 marta o'zgarishi kafolati. |
| **MAU** | Monthly Active Users | Bir oy davomida kamida 1 marotaba ilovadan foydalangan do'konlar soni. |
| **SKU** | Stock Keeping Unit | Tovar ombori hisobida har bir tovar turining unikal artikul/shtrix-kod kodi. |
| **HMAC-SHA256** | Hash-based Message Auth Code | Telegram Auth ma'lumotlarining buzilmaganini va soxtalashtirilmaganini tekshiruvchi kriptografik hash. |
| **Tenant Isolation** | Ijarachi Izolyatsiyasi | Bitta bazada har bir do meon faqat o me ma'lumotlarini ko meishi uchun qat'iy ajratish mexanizmi. |
| **Cold Start** | Uxlab Qolgan Server | Serverless function so'rov bo'lmagani uchun to'xtab qolishi va 1-so'rovda 1-2s sekinroq javob berishi. |
